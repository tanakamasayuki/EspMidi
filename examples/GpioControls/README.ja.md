# GpioControls

[English](README.md)

**つまみ 2 個・ボタン 2 個・エンコーダ 1 個の MIDI コントローラです。** 出力は USB MIDI と MIDI DIN の**両方に同時**に出ます。

[../../docs/USE_CASES.ja.md](../../docs/USE_CASES.ja.md) の UC10 です。ここではボードは MIDI ルータではなく **MIDI 機器**です。

## 構成

```text
つまみ・ボタン・エンコーダ ──→ [アプリケーションポート] ──→ USB MIDI
                                                      └─→ MIDI DIN OUT
USB MIDI ──→ LED(ノート 60)と調光(CC 20)
```

| コントロール | 送るもの |
| --- | --- |
| つまみ 1 / 2 | CC 7(Volume)/ CC 11(Expression) |
| ボタン 1 | ノート 60 |
| ボタン 2 | CC 64(Sustain)、**ラッチ**(モーメンタリスイッチをトグルとして使う) |
| エンコーダ | CC 16、相対(2 の補数) |

## 読みどころ

**ヘルパーはピンに触りません。** スケッチが読んだ値を渡すだけです。だから同じヘルパーが ADC でもポートエキスパンダでもタッチセンサでもネットワーク越しの値でも動きます。**時刻も引数**なので、デバウンスやテンポがテストできます([../../src/EspMidiControl.h](../../src/EspMidiControl.h))。

```cpp
knobs[i].update(analogRead(KNOB_PINS[i]));            // 値を渡すだけ
buttons[i].update(digitalRead(BUTTON_PINS[i]) == LOW, millis());
```

**つまみは動いたときだけ送ります。** ADC は 4096 段、CC は 128 段なので、ほとんどの動きは同じ値に着地します。加えて `hysteresis`(既定 8 カウント)があるので、**誰も触っていないつまみがリンクを CC で埋めることがありません**。

**LED 側は鏡像です。** どのメッセージに反応するかは `espmidi::Filter` で書きます — ルートに置くフィルタと同じものです。ノートオンでベロシティ 0 は消灯になるので、**LED が点いたままになりません**。

**エンコーダの相対形式は 3 種類選べます。** 標準が無く、間違えるとパラメータが逆に回るか動きません。

**アプリケーションポートに乗っているので、出力先は増やせます。** ルートを 1 本足せば BLE にも同時に出ます。

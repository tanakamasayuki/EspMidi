# SimpleMidiIn

[English](README.md)

**1 ポート・受信のみ。** 届いた MIDI をコンソールに表示します。

キーボードの MIDI OUT をつないで鍵盤を弾けば、何が送られているかが見えます。

## 配線

キーボードの MIDI OUT → **MIDI IN 回路(フォトカプラ)** → `RX_PIN`(既定 GPIO20)。

**MIDI DIN ソケットを GPIO に直結してはいけません。** MIDI は 5V のカレントループで、絶縁が必須です。3.3V の GPIO が壊れます([../../docs/MIDI_BASICS.ja.md](../../docs/MIDI_BASICS.ja.md))。

## 読みどころ

**`din.update()` と `router.update()` の 2 つが必要です。** 前者が線を読み、後者がルーティングを走らせてコールバックを呼びます。

**velocity 0 のノートオンはノートオフです。** このスケッチはそれを表示で区別しています。知らないと「音が鳴り止まない」バグになる、MIDI で最も定番の罠です。

**チャンネルは 0 始まりです。** 機器の表示に合わせるなら `channel() + 1` です。

**`message` の中のポインタはコールバックの間だけ有効です。** 後で使うならコピーします。

次は [`../SameCodeAnyPort/`](../SameCodeAnyPort/) です。ガイドは [../../docs/GUIDE.ja.md](../../docs/GUIDE.ja.md)。

## 準備と実行

1. [サンプル入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入条件と必要な機器を確認します。対応するボード・外部ライブラリはルートREADMEを参照します。
2. [SimpleMidiIn.ino](SimpleMidiIn.ino)を開き、実際のボードとポートを選びます。次のincludeで使う依存機能も準備してください。

   `<EspMidiUart.h>`

3. 書き込んだらシリアルモニタを115200 baudへ合わせます。起動ログとソースの操作条件を確認します。

## 動作の流れ

MIDI入力を受けて内容を確認する例です。詳細なAPIとデータの扱いは次の項目で確認します。

以下はソース内で最初に現れるAPIの順です。コールバック登録の位置は、実際の呼び出し順序とは異なります。

1. `din.begin(...)` — 前提となる機器を準備してから初期化し、結果を返すAPIでは成否を確認します。
2. `router.addRoute(...)` — 切断と意図しないループを考慮して、入力と出力のEndpoint／グループを登録します。
3. `din.update(...)` — 例にある実行場所から定期的に呼び、対象の処理を進めます。

変更する前に確認する定数: `RX_PIN`。GPIOやチャンネル、容量などは用途に合わせます。

## APIの使い方と注意点

各Transportとポートを初期化し、ルートを登録してから、例にあるRouter／ポート／スタックの処理を継続します。MIDIを転送するだけでは音は鳴らず、楽器やソフト音源へ接続します。USB／BLEの接続でポートの可用性は変わるため、グループや安定した識別子と、現在のEndpointは別の役割です。

双方向ルートを追加する際は意図しないループを防ぎ、注入したNote OnにNote Offを対応させます。UART MIDIにはDIN用の適切な電気回路が必要で、Socketへ直接GPIOをつなぐ配線ではありません。Filter追加時もPacket長とSysEx viewの寿命を保ちます。

コールバック引数への参照は永続領域ではありません。

## 操作と出力の見方

出力書式の一部は次のとおりです。printfの書式記号は実行時の値に変わります。表示順や数値は実行条件に応じて変わるので、その行へ進む条件と併せて確認します。

```text
note off
note on
control
```

## 確認と問題の切り分け

MIDI入力を受けて内容を確認することを出力から確認します。まず例のままの入力で試し、その後に設定やデータ源を1つずつ変えます。

| 症状 | 最初に確認すること |
|---|---|
| 出力がない | ボード／依存ライブラリ、初期化結果、表示先とシリアル速度 |
| 開始するが途中で止まる | 待機条件、バッファの空き、相手や入力の準備、継続呼び出し |
| 値が不自然・不安定 | 長さと単位、形式、寿命、共有状態、部分的な処理結果 |

共通の考え方は[入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)、別の例は[サンプル一覧](../README.ja.md)へ進んでください。

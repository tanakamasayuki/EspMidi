# manual/usb_host_real_devices

**実際の USB MIDI 機器**をつないで確認します。

`peer/usb_midi_host` が確認しているのは、こちらが作った device に対する動作です。**世の中の機器は descriptor の書き方も cable 数も癖があります**。

## 用意するもの

- `examples/UsbHostToUart` を書き込んだ ESP32-P4(または USB Host を持つ S3 構成)
- USB MIDI 機器いくつか。できれば次を含める
  - USB MIDI キーボード(cable 1 本)
  - パッド / コントローラ(CC を多く出すもの)
  - 複数ポートを持つ USB MIDI インターフェース(cable 2 本以上)
  - MIDI 以外の機能も持つ複合機器(オーディオインターフェース兼 MIDI など)
- セルフパワーの USB ハブ

## 手順と合格条件

### 1. 単体

各機器について:

- つなぐ。**コンソールに `port added:` が製品名付きで出る**
- 弾く / 動かす。**MIDI DIN 側の音源が鳴る**、および PC 側に届く
- 抜く。**`port state: ... disconnected` が出る**
- 挿し直す。**`available` に戻り、そのまま鳴る**(**ルートを張り直していない**のがポイント)

### 2. 複数ポートを持つ機器

- cable 2 本以上の機器をつなぐ。**ポートが cable 数だけ並ぶ**
- それぞれの cable から送る。**別のポートとして届く**(混ざらない)

### 3. 複数機器同時

- 2 台以上を(ハブ経由で)同時につなぐ。**両方の演奏が音源に届く**
- 片方だけ抜く。**もう片方は鳴り続ける**
- `ESPMIDI_MAX_USB_HOST_DEVICES`(既定 4)を超える台数をつなぐ。**既存の機器は動き続ける**

### 4. MIDI 以外の機器との共存

- USB キーボードやマウスを一緒につなぐ。**MIDI 機器が影響を受けない**
- 複合機器(オーディオ + MIDI)をつなぐ。**MIDI 部分が使える**

### 5. 癖の確認

- 電源投入直後に挿す / 挿したまま電源投入する。**どちらでも席ができる**
  - できない場合は「列挙は済んだが MIDI インターフェースの claim が遅い」ケース。polling が拾うので時間を置いて再確認する
- cable 数 0 の方向を持つ機器(送信専用のキーボードなど)。**その方向のポートが作られない**

## 記録

機器名・VID/PID・シリアルの有無・cable 数を表にして残します。**シリアルを持たない機器は再接続で新しい席になります**([../../docs/PORTS.ja.md](../../docs/PORTS.ja.md))。実機でそれが問題になるかどうかはここでしか分かりません。

# manual/usb_device_host_os

**PC / Mac / DAW からどう見えるか**を確認します。

`peer/usb_midi` は cable 数を descriptor から読んで assert していますが、**OS のポート一覧にどう並ぶか、名前がどう出るかは OS の実装次第**なので目視で確認します。

## 用意するもの

- `examples/UsbMidiDevice` を書き込んだ ESP32-S3(cable 数 2 / 2)
- Windows / macOS / Linux のいずれか(できれば複数)
- DAW または MIDI モニタ(MIDI-OX、MIDI Monitor、`amidi` など)

native USB 側を PC につなぎます。コンソールは外付け USB-serial チップ側です。

## 手順と合格条件

### 1. 認識

- USB をつなぐ。**ドライバのインストールなしで MIDI 機器として認識される**
- デバイスマネージャ / システム情報で製造元と製品名を確認する。**`EspMidi` / `EspMidi Interface` と出る**

### 2. ポート数

- MIDI モニタのポート一覧を見る。**入力 2 ポート・出力 2 ポートが並ぶ**
  - 1 ポートしか出ない場合は cable 数の宣言か descriptor の長さを疑う
- 名前を確認する。**OS が付ける名前**になる(cable ごとの名前は指定できない。[../../docs/PORTS.ja.md](../../docs/PORTS.ja.md) の現状の制約)

### 3. 往復

- ポート 2 の入力を監視し、ボードのボタンを押す。**ノートが届く**
- ポート 2 の出力へノートを送る。**コンソールに `from the PC:` が出る**
- ポート 1 は MIDI DIN 対につながっている。DIN 側の機器で確認する

### 4. 抜き差し

- USB を抜く。**OS のポート一覧から消える**
- 挿し直す。**再び現れ、往復が続く**
- **ボードをリセットせずに** PC 側だけスリープ・復帰させる。**復帰後も往復する**

### 5. 複数 OS

- 可能なら Windows と macOS の両方で 1〜3 を通す。**どちらでも同じポート数で見える**

## 記録

OS とそのバージョン、ポート一覧の実際の表示名、DAW の名前を書き残します。**名前の見え方は OS ごとに違う**ので、期待値を 1 つに決めずに実例を残します。
